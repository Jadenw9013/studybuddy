# Trust, cost and operational readiness

## Who can use the pilot

Launch invite-only to U.S. adults in graduate or professional training. Enroll through known adult cohorts, require adult confirmation, and keep the product and recruitment adult-directed. A checkbox alone does not establish that a general student site is unlikely to be accessed by minors. Review the actual distribution channel, terms and account before external rollout. For parents interested in school-age learners, conduct interviews using static materials with adults only. The chosen Gemini Developer API restricts services directed toward, or likely to be accessed by, under-18s. New provider terms or a different deployment agreement require an explicit future decision. [Google's terms](https://ai.google.dev/gemini-api/terms)

Use a business-owned paid provider project for real learner content. Verify usage tier, data processing terms, regional availability, provider retention/abuse monitoring, and model access for the actual account. For development fixtures, use synthetic materials. In product copy distinguish “we do not save your live recording” from processing by vendors. Show the data flow before upload and before first capture. Respect the course policy and the uploader's rights to use the materials.

## Minimal permissions, by action

| Action | Data leaving device | Grant and student override |
|---|---|---|
| Upload course files | Selected originals to private app storage. Extracted passages go to the tutor model only when used. Embeddings generated by the app worker. | Learner chooses files and sees status, retention and delete. No file-system scanning. |
| Talk or type | Active audio to the relay/provider; typed messages and selected context to the tutor model. | Mic only during live; mute, quiet work, text and end controls. Do not retain raw audio or live transcripts by default. Explain persistent typed chat and saved recap. |
| Share a screen | Selected window/tab frames or explicit crop when sampled; no system audio by default. | Browser chooser + visible capture indicator + Stop. Default to avoiding the entire desktop. No automatic screen recording. |
| Connect Jupyter | Notebook/cell identifiers, selected text and needed context. No unrelated notebook contents. | Pair per lesson, request point/highlight grant, local approval for one exact text change. Revocation works even if the connection drops. |
| Optional image | A purpose-written illustration prompt, with no private sources by default. | Separate feature flag and cost limit. Do not send raw screenshots or original course files to this provider automatically. |

Use TLS, private buckets, expiring upload grants, authenticated document reads, scoped tokens, rate limits, ownership checks and redacted errors. Disable raw prompt, page text, email, filename, image and transcript logging in analytics, SDK tracing, error handlers and outbound proxies. Use pseudonymous event IDs. Limit reviewer access to consented, de-identified evaluation transcripts; set an explicit pilot-review expiry (default 30 days). Document deletion and backup schedules in the real deployment.

## Quotas and costs

Pilot defaults: 80 live minutes per paid four-week period, max 20 minutes per live session. Warn at two minutes remaining and at 30 seconds; end voice gracefully, keep the lesson, offer text. A partial session debits actual active seconds and preserves remaining minutes. In authenticated pilot chat start with 50 turns/day and the course/file caps in [data](05-data.md). Show actual limits in the offer and UI; don't advertise unlimited use. A non-paid trial demo uses a separate capped entitlement.

Reserve capacity before opening a live session. Use a unique meter event ID, atomic quota decrement/settlement, a five-second heartbeat, and a bounded expiry for abandoned reservations. Prevent two tabs from double-spending the same entitlement. Stop sending audio/frames and close provider sessions in quiet mode; show a resume control. Configure per-user and project-level budget limits, alerts, and a global paid-call kill switch. If cost caps trip, disable the expensive feature and preserve course access. Usage and pricing are provider-specific; update rates before enabling real payments.

Per lesson record: provider/model, billed input/output/cached units where applicable, image units, active seconds, retrieval/worker charges and estimated marginal infrastructure cost. Capture a rate-table version. Validate estimates against vendor invoices on sampled sessions. At the $19 pilot offer, a provisional 60% variable margin leaves **$7.60** total variable cost for the entire four-session pass, before fixed expenses. Include processing fees and chat in cost accounting. This is a decision threshold, not an observed margin. Reprice or reduce the included allowance if real usage exceeds it.

## Failure playbook

| Symptom | What learners experience | Operator action and verification |
|---|---|---|
| Live auth, capacity or transport fails | Clear status, one bounded retry with backoff; resume or use text. | Check region, model access, provider status and quota. No infinite reconnects or repeated greetings. |
| Model fails to call the right tool | Ask a clarifying question or show an explicit manual control. | Inspect action-type/error counters and replay a synthetic case; never add broad access to fix a targeting bug. |
| File parser is down / indexing backlog | Existing ready sources still work. Pending sources show status and retry. | Check lease expiry, retry count, CPU/memory; quarantine bad input. |
| Edit acknowledgement missing | “Checking edit” and read-only state. | Query action ID and notebook hash; reconcile or show conflict. No automatic second write. |
| Wrong/stale evidence, mistaken edit or cross-account access | Stop the affected mode, preserve user control and offer undo when safe. | Revoke keys/grants where applicable, disable feature, review redacted traces, reproduce, correct, verify isolation before enabling. |
| Model renamed/unavailable | Honest feature status. Typed fallback only if explicitly tested and working. | Run capability probe and regression suite against a supported replacement, then promote versioned configuration. |

Track distinct timings: end-of-speech → first useful audio; end-of-speech → first correct painted board; local interrupt → playback silence; file upload → source ready. Include silent failures and wrong targets in denominators. Track device, network profile, warm/cold session and lookup type. No raw screen or audio is required for operational timing. Record which metrics are measured versus unavailable.

## Admission, fulfillment and telemetry

Pre-provision invited adults, disable public signups for the pilot, and request Supabase email OTP with automatic user creation disabled. Configure an email template with the one-time code and custom SMTP before sending to external learners. Provide manual paste and resend. Exercise this with a real school or work mailbox and synthetic test accounts in staging.

The server creates a one-time Stripe Checkout Session for the authenticated account, an approved Price ID, amount/currency and a pending purchase record. Verify webhook signatures against the raw request body. Fulfill only confirmed paid sessions matched to the expected account, purchase and environment. Check provider state if events arrive late or out of order. In one database transaction insert a unique fulfillment for the Checkout Session and grant the allowance. Duplicate events, a retry and staff reconciliation all enter the same handler. Show “confirming payment” if the student returns before the webhook. A success-page visit, copied URL or email match grants no minutes. Track refunds by purchase, preserve consumed usage, and apply the documented unused balance/refund policy. Test in Stripe test mode before real payment.

Store an allowlisted set of timing, result, revision and usage fields. Use redacted structured logs and counters first; introduce an external telemetry service only if needed. Disable raw provider payloads and media in traces. Measure provider-reported usage per turn, including retained context and transcription. Bound the live history and rehydrate from a concise confirmed lesson summary. A short session's per-minute price must not stand in for a full lesson bill. Distinguish active time debited from learner entitlement, vendor cost during reconnect, and released reservations.

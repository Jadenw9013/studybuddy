# Lesson workspace design

The brief specifies warm neutral surfaces and teal controls. Tokens: paper #f7f6f2, workspace #edf2f0, ink #183634, muted #526663, teal #176b62, preview amber #8b5d14. System sans for controls; Georgia for readable problem titles; monospace only for notebook code. A 16px body and 8px rhythm keep the visual hierarchy quiet.

The source pane and comparison board are the visual center; the histogram is the memorable element. A narrow course rail, wide work area, compact conversation strip and persistent lesson controls support the actual statistics task. On narrow windows the surfaces stack with labeled work and board controls. Content stays left aligned. Source receipts and practice evidence use their own readable rows rather than dashboard cards.

Review against the brief: no marketing hero, avatar, invented progress or empty chat home. Neutral paper and teal come from the explicit specification. Boundaries distinguish source evidence, computed results and learner attempts. Charts include an equivalent table and selectable labels.
